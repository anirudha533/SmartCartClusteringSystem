# SmartCart – Intelligent Customer Segmentation System

## Problem Statement
SmartCart is a growing e-commerce platform serving customers across multiple countries. 
The company has collected extensive customer data consisting of 2,240 customer records 
and 22 attributes, including demographics, purchase behaviour, website activity, and 
campaign response.

## Objective

To solve this, SmartCart aims to build an **intelligent customer segmentation system** 
using **unsupervised machine learning**. The system will analyse historical customer 
transaction data and group customers into meaningful clusters based on purchasing 
behaviour, engagement levels, and loyalty indicators.

## Role
To develop this system using 
**clustering techniques** to discover hidden patterns in customer behaviour and support 
personalised marketing and customer retention strategies.

## Dataset

- **Records:** 2,240 customers
- **Attributes:** 22, including:
  - Demographics (age, income, education, marital status, etc.)
  - Purchase behaviour (spending across product categories)
  - Website/engagement activity (visits, purchases via web/catalog/store)
  - Campaign response history

 ## Approach

1. Data cleaning and preprocessing
2. Exploratory data analysis (EDA) on customer attributes
3. Feature engineering (e.g., customer tenure, total spend, engagement score)
4. Dimensionality reduction (e.g., PCA) if needed
5. Unsupervised clustering (e.g., K-Means, Hierarchical Clustering, DBSCAN)
6. Cluster profiling and interpretation
7. Recommendations for targeted marketing and retention strategies per segment

## Expected Outcome

- Well-defined customer segments based on behaviour and value
- Actionable insights to identify high-value and churn-prone customers
- A foundation for personalised marketing campaigns and improved customer retention

## Tech Stack

- Python (Pandas, NumPy, Scikit-learn)
- Data visualization (Matplotlib, Seaborn)
- Jupyter Notebook
